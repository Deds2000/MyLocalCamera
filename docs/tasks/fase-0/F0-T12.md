## Passos
1. `cargo new crates/lc-testkit --lib --vcs none`; use `*.workspace = true` para edition/license/version; adicione `"crates/lc-testkit"` aos `members` da raiz.
2. Dependências:
   ```powershell
   cargo add -p lc-testkit tracing
   cargo add -p lc-testkit tracing-subscriber --features env-filter
   cargo add -p lc-protocol --dev proptest
   cargo add -p mock-sender tokio --features rt-multi-thread,macros,time,net,io-util,sync
   cargo add -p mock-sender --dev tokio --features test-util
   ```
   (Confira os nomes de features com `cargo add --help`/docs.rs se algum falhar.)
3. `crates/lc-testkit/src/lib.rs`:
   ```rust
   //! Utilitários compartilhados por testes e ferramentas.
   use std::net::TcpListener;

   /// Devolve uma porta TCP livre em 127.0.0.1 (a porta fica livre ao retornar).
   pub fn free_port() -> u16 {
       let l = TcpListener::bind("127.0.0.1:0").expect("bind");
       l.local_addr().expect("addr").port()
   }

   /// Inicializa logs para testes (idempotente). Use RUST_LOG=debug para ver.
   pub fn init_tracing() {
       let _ = tracing_subscriber::fmt()
           .with_test_writer()
           .with_env_filter(tracing_subscriber::EnvFilter::from_default_env())
           .try_init();
   }

   #[cfg(test)]
   mod tests {
       use super::*;
       #[test]
       fn free_port_is_bindable() {
           let p = free_port();
           assert!(p > 0);
           assert!(std::net::TcpListener::bind(("127.0.0.1", p)).is_ok());
       }
   }
   ```
4. Teste de sanidade do `proptest` em `crates/lc-protocol/src/lib.rs` (substitua o teste do template):
   ```rust
   #[cfg(test)]
   mod infra_tests {
       use proptest::prelude::*;
       proptest! {
           #[test]
           fn proptest_infra_works(a in any::<u32>(), b in any::<u32>()) {
               prop_assert_eq!(a as u64 + b as u64, b as u64 + a as u64);
           }
       }
   }
   ```
5. `cargo fmt --all`.
