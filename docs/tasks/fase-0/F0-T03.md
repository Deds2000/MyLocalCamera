# F0-T03 — App mobile: Capacitor + React 19 + Tailwind 3.4 + shadcn

**Fase:** 0 · **Executor:** agente+humano · **Depende de:** F0-T04 · **Tempo:** ~3 h · **Contexto estimado:** ~12k tokens

## Objetivo
Um app Capacitor (Android) que abre num celular real mostrando componentes shadcn estilizados pelo preset. O agente prepara e builda o APK; o **humano instala e confere** no aparelho.

## Leia só isto
Documentação oficial (web) do Capacitor: "Android — Getting Started". Use para confirmar comandos.

## Contexto embutido
- `appId`: `com.localcamera.app` · `appName`: `LocalCamera` · `webDir`: `dist`.
- **Capacitor 8.5** foi a versão pedida pelo usuário. Teste `pnpm view @capacitor/core versions --json`: se existir `8.5.x`, use `~8.5`; **se não existir, PARE e pergunte ao usuário qual versão usar** (não mude de major sozinho).
- Sem `framer-motion` no mobile. Tailwind **3.4**. shadcn/ui gerado para Tailwind 3.
- UI travada em retrato. `android:allowBackup="false"`.
- Pacote Kotlin do plugin (fases futuras): `com.localcamera.app`.

## Passos
1. Gere o projeto Vite (remova antes o `.gitkeep` de `mobile/` se existir):
   ```powershell
   pnpm create vite@latest mobile --template react-ts
   ```
   Apague `mobile/pnpm-lock.yaml`/`.git` se aparecerem. Garanta React 19.
2. `mobile/package.json`: `"name": "mobile"`; scripts `"lint": "eslint ."`, `"typecheck": "tsc --noEmit"`, `"test": "vitest run --passWithNoTests"`, `"build": "vite build"`. O `tsconfig` deve **estender** `../tsconfig.base.json`.
3. Dependências:
   ```powershell
   pnpm --filter mobile add @localcamera/shared@workspace:* lucide-react clsx tailwind-merge class-variance-authority tailwindcss-animate @fontsource-variable/inter @fontsource-variable/jetbrains-mono i18next react-i18next
   pnpm --filter mobile add -D tailwindcss@3.4 postcss autoprefixer
   ```
4. Tailwind/PostCSS/CSS/alias `@`/shadcn: **mesmos passos 4–10 do cartão `F0-T02`** (arquivos em `mobile/`), com estas diferenças: **não** use framer-motion; `body` com `@apply bg-bg text-text font-sans`; adicione no `index.css` o `padding` de *safe-area*: `body { padding-top: env(safe-area-inset-top); padding-bottom: env(safe-area-inset-bottom); }`.
5. `mobile/src/App.tsx`: página de teste com `Button`, `Tabs` e `Dialog`; textos por i18n (chaves `mobile.smoke.*` nos DOIS JSON de `packages/shared/src/i18n`).
6. Capacitor:
   ```powershell
   pnpm --filter mobile add @capacitor/core@~8.5 @capacitor/app@~8.5
   pnpm --filter mobile add -D @capacitor/cli@~8.5
   pnpm --filter mobile add @capacitor/android@~8.5
   cd mobile
   pnpm exec cap init LocalCamera com.localcamera.app --web-dir=dist
   pnpm build
   pnpm exec cap add android
   pnpm exec cap sync android
   cd ..
   ```
   (Se `@~8.5` não existir, veja a regra de versão em **Contexto embutido**.)
7. `mobile/capacitor.config.ts`: confira `appId`, `appName`, `webDir: "dist"`. **Não** habilite `server.cleartext` nem `allowNavigation`.
8. `mobile/android/app/src/main/AndroidManifest.xml`:
   - no elemento `<application`: `android:allowBackup="false"`;
   - na `<activity` principal: `android:screenOrientation="portrait"` e **mantenha** `android:exported="true"` apenas nela;
   - adicione dentro da `<activity>` principal o intent-filter do esquema (será usado na Fase 2):
     ```xml
     <intent-filter>
         <action android:name="android.intent.action.VIEW" />
         <category android:name="android.intent.category.DEFAULT" />
         <category android:name="android.intent.category.BROWSABLE" />
         <data android:scheme="localcamera" android:host="connect" />
     </intent-filter>
     ```
   - confirme que **não** há permissões desnecessárias além de `INTERNET`.
9. Gere o APK de debug:
   ```powershell
   cd mobile\android
   .\gradlew.bat assembleDebug 2>&1 | Select-Object -Last 25
   cd ..\..
   ```
   O APK fica em `mobile\android\app\build\outputs\apk\debug\app-debug.apk`.
10. **[Humano]** Com o celular em depuração USB: `adb devices` (deve listar o aparelho) → `adb install -r mobile\android\app\build\outputs\apk\debug\app-debug.apk` → abrir o app **LocalCamera**. Conferir: fundo escuro, componentes com o tema ciano/azul, UI em retrato, nenhum texto cortado pela barra de status. Responder no chat: "OK" ou o que viu.
