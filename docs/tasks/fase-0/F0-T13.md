## Contexto embutido
**Formato Annex-B:** NAL units separados por start codes `00 00 01` ou `00 00 00 01`; o tipo da NAL é `byte & 0x1F` do byte após o start code. Tipos úteis: **9 = AUD** (delimitador de access unit), **7 = SPS**, **8 = PPS**, **5 = slice IDR (keyframe)**, **1 = slice não-IDR**. Geramos com `aud=1`, então **cada access unit (AU) começa com um AUD**.
**Padrão `lc-pattern`:** 4 quadrantes de cores fixas (sup-esq vermelho, sup-dir verde, inf-esq azul, inf-dir amarelo) + faixa superior de 16 blocos que codifica o **contador de quadros** (bit `i` do número do quadro `n`: bloco branco = 1, preto = 0).

   ```rust
   use std::ops::Range;

   /// Tipos de NAL presentes em `data`, na ordem.
   pub fn nal_types(data: &[u8]) -> Vec<u8> {
       let mut out = Vec::new();
       let mut i = 0;
       while i + 3 < data.len() {
           if data[i] == 0 && data[i + 1] == 0 && data[i + 2] == 1 {
               out.push(data[i + 3] & 0x1F);
               i += 3;
           } else {
               i += 1;
           }
       }
       out
   }

   /// Intervalos de cada access unit (cada AU começa em um AUD, NAL tipo 9).
   pub fn split_access_units(data: &[u8]) -> Vec<Range<usize>> {
       let mut starts = Vec::new();
       let mut i = 0;
       while i + 3 < data.len() {
           if data[i] == 0 && data[i + 1] == 0 && data[i + 2] == 1 {
               if data[i + 3] & 0x1F == 9 {
                   let s = if i > 0 && data[i - 1] == 0 { i - 1 } else { i };
                   starts.push(s);
               }
               i += 3;
           } else {
               i += 1;
           }
       }
       let mut ranges = Vec::new();
       for (k, &s) in starts.iter().enumerate() {
           let end = starts.get(k + 1).copied().unwrap_or(data.len());
           ranges.push(s..end);
       }
       ranges
   }

   /// true se o AU contém um slice IDR (tipo 5).
   pub fn is_idr(au: &[u8]) -> bool {
       nal_types(au).contains(&5)
   }
   ```
