# F0-T06 — CI local (`scripts/ci.ps1`) e hook de `pre-push`

**Fase:** 0 · **Executor:** agente · **Depende de:** F0-T09, F0-T12 · **Tempo:** ~1,5 h · **Contexto estimado:** ~8k tokens

## Objetivo
Um único comando que roda todas as verificações e mostra um resumo **etapa × tempo × resultado**, e um hook de `pre-push` que roda a versão rápida.

## Leia só isto
Nada além deste cartão.

## Contexto embutido
- Modos: **completo** (lint, typecheck, testes JS, `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test`, testes e lint do Android) e **`-Fast`** (lint, typecheck, testes JS, fmt, clippy — sem `cargo test` e sem Android; alvo ≤ 3 min).
- Opções: `-SkipAndroid`, `-Only all|ts|rust|android`, `-KeepGoing`.
- Código de saída ≠ 0 se algo falhar. Hook usa `-Fast`.

## Passos
1. Crie `scripts/ci.ps1` com este conteúdo:
   ```powershell
   <#
   .SYNOPSIS  CI local do LocalCamera.
   .PARAMETER Fast         lint + typecheck + testes JS + fmt/clippy (sem cargo test e sem Android)
   .PARAMETER SkipAndroid  não roda os testes do Android
   .PARAMETER Only         all | ts | rust | android
   .PARAMETER KeepGoing    continua após falhas
   #>
   param(
     [switch]$Fast,
     [switch]$SkipAndroid,
     [ValidateSet('all','ts','rust','android')][string]$Only = 'all',
     [switch]$KeepGoing
   )
   $ErrorActionPreference = 'Stop'
   Set-Location (Split-Path $PSScriptRoot -Parent)
   $script:results = New-Object System.Collections.Generic.List[object]
   $script:failed = $false

   function Invoke-Step {
     param([string]$Name, [scriptblock]$Block)
     if ($script:failed -and -not $KeepGoing) {
       $script:results.Add([pscustomobject]@{ Step = $Name; Seconds = '-'; Result = 'SKIPPED' }); return
     }
     Write-Host "==> $Name" -ForegroundColor Cyan
     $global:LASTEXITCODE = 0
     $sw = [Diagnostics.Stopwatch]::StartNew()
     $ok = $true
     try { & $Block; if ($LASTEXITCODE -ne 0) { $ok = $false } }
     catch { Write-Host $_ -ForegroundColor Red; $ok = $false }
     $sw.Stop()
     if (-not $ok) { $script:failed = $true }
     $script:results.Add([pscustomobject]@{
       Step = $Name; Seconds = [math]::Round($sw.Elapsed.TotalSeconds, 1); Result = $(if ($ok) { 'OK' } else { 'FAIL' })
     })
   }

   $runTs      = $Only -in 'all','ts'
   $runRust    = $Only -in 'all','rust'
   $runAndroid = ($Only -in 'all','android') -and (-not $SkipAndroid) -and (-not $Fast)

   if ($runTs) {
     Invoke-Step 'pnpm install'  { pnpm install --frozen-lockfile }
     Invoke-Step 'lint'          { pnpm lint }
     Invoke-Step 'typecheck'     { pnpm typecheck }
     Invoke-Step 'testes JS'     { pnpm test }
   }
   if ($runRust) {
     Invoke-Step 'cargo fmt'     { cargo fmt --all -- --check }
     Invoke-Step 'cargo clippy'  { cargo clippy --workspace --all-targets -- -D warnings }
     if (-not $Fast) { Invoke-Step 'cargo test' { cargo test --workspace } }
   }
   if ($runAndroid) {
     Invoke-Step 'android unit+lint' {
       Push-Location mobile/android
       try { .\gradlew.bat testDebugUnitTest lintDebug } finally { Pop-Location }
     }
   }

   Write-Host ''
   $script:results | Format-Table -AutoSize
   if ($script:failed) { Write-Host 'CI: FALHOU' -ForegroundColor Red; exit 1 }
   Write-Host 'CI: OK' -ForegroundColor Green; exit 0
   ```
2. `.githooks/pre-push` (finais de linha **LF**):
   ```sh
   #!/bin/sh
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/ci.ps1 -Fast
   exit $?
   ```
3. Ative o hook: `pnpm run prepare` (ou `git config core.hooksPath .githooks`). Confirme com `git config core.hooksPath`.
4. Se `cargo clippy` do Tauri ficar lento demais no modo `-Fast` (> 3 min repetidamente), exclua apenas a crate do Tauri nesse modo (`--exclude <nome-da-crate>`), anote em `PROGRESS.md` e deixe o modo completo cobrindo tudo.
5. Rode o CI completo e o rápido; depois execute os **testes negativos** abaixo.
