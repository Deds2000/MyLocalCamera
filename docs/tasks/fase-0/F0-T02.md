# F0-T02 — App desktop: Tauri 2 + React 19 + Tailwind 3.4 + shadcn/ui

**Fase:** 0 · **Executor:** agente · **Depende de:** F0-T04 · **Tempo:** ~3 h (o 1º build Rust é lento) · **Contexto estimado:** ~12k tokens

## Objetivo
Um app Tauri 2 que abre uma janela mostrando componentes shadcn (`Button`, `Tabs`, `Dialog`) estilizados pelos tokens do preset. É só o esqueleto: nada de funcionalidade.

## Leia só isto
Documentação oficial (web): "Create a Tauri project" (v2.tauri.app). Use-a para confirmar o comando e as opções do `create-tauri-app`.

## Contexto embutido
- Identificador Tauri: `com.localcamera.desktop`; nome do produto: `LocalCamera`.
- Janela: título `LocalCamera`, 1280×800, mínima 960×640, **sem decoração** (`decorations: false`).
- Pasta do app: `desktop/` (frontend em `desktop/src`, Rust em `desktop/src-tauri`).
- **Tailwind deve ser 3.4** (nunca 4). shadcn/ui precisa gerar para Tailwind 3.4 + React 19.
- Alias `@` → `desktop/src`.
- **CSP restritiva** (nada de recursos remotos).

## Passos
1. Gere o projeto (na raiz do repo). Se a pasta `desktop` já existir vazia (`.gitkeep`), remova o `.gitkeep` antes:
   ```powershell
   pnpm create tauri-app@latest desktop
   ```
   Respostas: gerenciador **pnpm**, linguagem **TypeScript/JavaScript → TypeScript**, template **React → TypeScript**. Identificador: `com.localcamera.desktop`. Se o assistente criar `desktop/pnpm-lock.yaml` ou `.git`, apague-os.
2. Ajuste `desktop/package.json`: `"name": "desktop"`, e scripts `"lint": "eslint ."`, `"typecheck": "tsc --noEmit"`, `"test": "vitest run --passWithNoTests"` (o Vitest entra no F0-T09). Garanta React **19** (`pnpm --filter desktop add react@19 react-dom@19` e `@types/react@19 @types/react-dom@19` se o template trouxer outra versão).
3. Dependências do frontend:
   ```powershell
   pnpm --filter desktop add @localcamera/shared@workspace:* framer-motion lucide-react clsx tailwind-merge class-variance-authority tailwindcss-animate @fontsource-variable/inter @fontsource-variable/jetbrains-mono i18next react-i18next
   pnpm --filter desktop add -D tailwindcss@3.4 postcss autoprefixer
   ```
4. `desktop/postcss.config.js`: `export default { plugins: { tailwindcss: {}, autoprefixer: {} } };`
5. `desktop/tailwind.config.ts`:
   ```ts
   import type { Config } from "tailwindcss";
   import preset from "@localcamera/shared/tailwind-preset";
   import animate from "tailwindcss-animate";

   export default {
     presets: [preset],
     darkMode: "class",
     content: [
       "./index.html",
       "./src/**/*.{ts,tsx}",
       "../packages/shared/src/**/*.{ts,tsx}",
     ],
     plugins: [animate],
   } satisfies Config;
   ```
6. `desktop/src/index.css`:
   ```css
   @import "@localcamera/shared/tokens.css";
   @tailwind base;
   @tailwind components;
   @tailwind utilities;

   html, body, #root { height: 100%; }
   body { @apply bg-bg text-text font-sans antialiased; }
   ```
   (Se o `@import` do pacote não resolver no Vite, copie o conteúdo de `tokens.css` para o topo deste arquivo e registre uma observação em `PROGRESS.md`.)
7. `desktop/src/main.tsx`: importe `@fontsource-variable/inter`, `@fontsource-variable/jetbrains-mono`, `./index.css`; adicione `document.documentElement.classList.add("dark")`; renderize `<App />` em `React.StrictMode`.
8. Alias `@`: em `desktop/vite.config.ts` → `resolve: { alias: { "@": path.resolve(__dirname, "./src") } }` (importe `path` de `node:path`); em `desktop/tsconfig.json` → `compilerOptions.baseUrl: "."` e `paths: { "@/*": ["./src/*"] }`; faça o `tsconfig` **estender** `../tsconfig.base.json`.
9. `desktop/src/lib/utils.ts`: `export { cn } from "@localcamera/shared/cn";`
10. shadcn/ui para **Tailwind 3**:
    - Crie `desktop/components.json`:
      ```json
      {
        "$schema": "https://ui.shadcn.com/schema.json",
        "style": "default",
        "rsc": false,
        "tsx": true,
        "tailwind": { "config": "tailwind.config.ts", "css": "src/index.css", "baseColor": "slate", "cssVariables": true },
        "aliases": { "components": "@/components", "utils": "@/lib/utils", "ui": "@/components/ui" }
      }
      ```
    - Tente adicionar os componentes com a CLI **compatível com Tailwind 3** (confirme na documentação do shadcn/ui qual versão da CLI/ramo "v3" usar): `pnpm dlx shadcn@<versão-v3> add button tabs dialog` dentro de `desktop/`.
    - **Se a CLI gerar config/CSS para Tailwind 4 ou falhar:** NÃO prossiga com ela. Copie manualmente o código de `button.tsx`, `tabs.tsx`, `dialog.tsx` da documentação **v3** do shadcn/ui e instale as dependências Radix necessárias (`@radix-ui/react-slot`, `@radix-ui/react-tabs`, `@radix-ui/react-dialog`). Anote em `PROGRESS.md` (Observações) qual caminho foi usado.
11. `desktop/src/App.tsx`: página de teste com um `Button` primário, um `Tabs` de duas abas e um `Dialog`; **todo texto via i18n** (use `useTranslation` do `react-i18next` com `createI18n` de `@localcamera/shared/i18n`; adicione as chaves `desktop.smoke.title`, `desktop.smoke.open`, `desktop.smoke.tabA`, `desktop.smoke.tabB`, `desktop.smoke.dialogTitle` nos DOIS JSON de `packages/shared/src/i18n`, com texto em pt-BR e en).
12. `desktop/src-tauri/tauri.conf.json` (confirme os nomes dos campos do **Tauri 2** na documentação ao editar):
    - `productName: "LocalCamera"`, `identifier: "com.localcamera.desktop"`;
    - janela: `title: "LocalCamera"`, `width: 1280`, `height: 800`, `minWidth: 960`, `minHeight: 640`, `decorations: false`;
    - `app.security.csp`: `"default-src 'self'; img-src 'self' data: blob:; style-src 'self' 'unsafe-inline'; script-src 'self'; font-src 'self' data:; connect-src 'self' ipc: http://ipc.localhost"` (confirme na documentação o valor de `connect-src` para o IPC do Tauri 2);
    - não habilite plugins nem capacidades além do padrão do template.
13. Remova do template o que não usa (logos, exemplo `greet`), **mantendo** o comando Rust compilando.
14. Rode o app.

## Não faça
- Não use Tailwind 4, nem `@tailwindcss/vite`.
- Não importe `framer-motion` nos componentes do pacote compartilhado (aqui no app pode).
- Não escreva texto fixo em JSX (o lint de i18n vai falhar).
- Não adicione plugins Tauri nem lógica de rede agora.
