## Objetivo
Habilitar **Kotlin** no projeto Android do Capacitor e deixar prontos os testes unitários (JVM) e instrumentados (no aparelho), com um teste de exemplo de cada.

## Leia só isto
Documentação oficial (web): "Add Kotlin to an existing app" (developer.android.com). Use para confirmar o plugin e a versão compatível com o AGP do projeto.

## Contexto embutido
- O template do Capacitor usa **Java** (MainActivity.java). Os plugins do projeto serão em **Kotlin**; os dois idiomas convivem.
- Pacote dos testes: `com.localcamera.app`.
- Para relógio virtual em testes de coroutines: `kotlinx-coroutines-test`.
- Nunca "chute" versões: consulte a tabela de compatibilidade Kotlin × AGP × Gradle da documentação e use a versão do AGP **já presente** em `mobile/android/build.gradle`.

## Passos
1. Abra `mobile/android/build.gradle` e `app/build.gradle`. Anote: versão do **AGP**, do **Gradle** (`gradle/wrapper/gradle-wrapper.properties`) e se já existe o plugin `kotlin-android`/`org.jetbrains.kotlin.android`.
2. Se **não** existir, adicione o plugin Kotlin na versão compatível (confirme na documentação) — no `build.gradle` raiz (classpath ou bloco `plugins` conforme o estilo do template) e aplique em `app/build.gradle`:
   `apply plugin: 'org.jetbrains.kotlin.android'` (ou `id 'org.jetbrains.kotlin.android'` no bloco `plugins`).
   Garanta `kotlinOptions { jvmTarget = '17' }` (ou o alvo que o template usar para Java — **os dois devem coincidir**).
3. Dependências de teste em `app/build.gradle` (o template já traz JUnit e `androidx.test`; **reaproveite** as variáveis existentes e adicione só o que falta):
   ```gradle
   dependencies {
       testImplementation "junit:junit:$junitVersion"
       testImplementation "org.jetbrains.kotlinx:kotlinx-coroutines-test:<versão compatível>"
       androidTestImplementation "androidx.test.ext:junit:$androidxJunitVersion"
       androidTestImplementation "androidx.test.espresso:espresso-core:$androidxEspressoCoreVersion"
   }
   ```
   (Se as variáveis `$junitVersion` etc. não existirem, copie o que o template usa.)
4. `SmokeTest.kt`:
   ```kotlin
   package com.localcamera.app

   import kotlinx.coroutines.ExperimentalCoroutinesApi
   import kotlinx.coroutines.delay
   import kotlinx.coroutines.launch
   import kotlinx.coroutines.test.advanceTimeBy
   import kotlinx.coroutines.test.runCurrent
   import kotlinx.coroutines.test.runTest
   import org.junit.Assert.assertEquals
   import org.junit.Test

   @OptIn(ExperimentalCoroutinesApi::class)
   class SmokeTest {
       @Test
       fun virtualTimeWorks() = runTest {
           var ticks = 0
           launch { repeat(3) { delay(1000); ticks++ } }
           advanceTimeBy(2500); runCurrent()
           assertEquals(2, ticks)
       }
   }
   ```
5. `InstrumentedSmokeTest.kt` (roda no aparelho):
   ```kotlin
   package com.localcamera.app

   import androidx.test.platform.app.InstrumentationRegistry
   import androidx.test.ext.junit.runners.AndroidJUnit4
   import org.junit.Assert.assertEquals
   import org.junit.Test
   import org.junit.runner.RunWith

   @RunWith(AndroidJUnit4::class)
   class InstrumentedSmokeTest {
       @Test
       fun packageNameIsCorrect() {
           val ctx = InstrumentationRegistry.getInstrumentation().targetContext
           assertEquals("com.localcamera.app", ctx.packageName)
       }
   }
   ```
6. Rode os testes unitários e o lint:
   ```powershell
   cd mobile\android
   .\gradlew.bat testDebugUnitTest lintDebug 2>&1 | Select-Object -Last 30
   cd ..\..
   ```
7. **[Humano]** Com o celular conectado e depuração USB ativa: `cd mobile\android ; .\gradlew.bat connectedDebugAndroidTest` e informe no chat o resultado (`BUILD SUCCESSFUL` e "1 tests completed" ou o erro).
