# F0-S1 — Spike S1: câmera virtual × NVIDIA Broadcast

**Fase:** 0 · **Executor:** agente+humano · **Depende de:** F0-T01 · **Tempo:** ~1–2 dias · **Contexto estimado:** ~10k tokens

## Objetivo
Descobrir se uma câmera virtual por **Media Foundation** (`MFCreateVirtualCamera`) aparece e funciona em apps reais — **principalmente como entrada do NVIDIA Broadcast** — e, se não, se um filtro **DirectShow** resolve. O resultado decide como a Fase 4 será implementada.

## Leia só isto
Documentação oficial: página da API `MFCreateVirtualCamera` (Microsoft Learn) e o README do exemplo `Windows-Camera/Samples/VirtualCamera` (repositório `microsoft/Windows-Camera`; **confirme o caminho atual**).

## Contexto embutido
- A DLL da fonte de mídia é carregada pelo **Frame Server** (outro usuário/sessão): instalar em `C:\Program Files\LocalCameraSpike\`, nunca na pasta do usuário.
- Registrar o CLSID da DLL exige **administrador** (`regsvr32`).
- Este spike é **descartável**: o código fica em `spikes/s1/` e **não** entra no build do produto.
- Apps da matriz: Câmera do Windows · Configurações → Câmeras · Chrome (Google Meet) · OBS · Zoom · Teams · Discord · **NVIDIA Broadcast**.

## Divisão de trabalho
**Agente:** clonar o exemplo, compilar, escrever os scripts e o modelo de relatório. **Humano:** executar a instalação com UAC e preencher a matriz.

## Passos
### Parte do agente
1. Crie `spikes/s1/` e adicione `spikes/s1/_vendor/` ao `.gitignore`. Clone o exemplo da Microsoft em `spikes/s1/_vendor/Windows-Camera` (`git clone --depth 1 https://github.com/microsoft/Windows-Camera`).
2. Leia o README do exemplo `Samples/VirtualCamera` e compile com Visual Studio 2022 (`msbuild` ou `devenv`). Anote em `spikes/s1/NOTAS.md`: caminho da DLL gerada, quais executáveis existem (registro/host), parâmetros usados em `MFCreateVirtualCamera` (tipo, tempo de vida, acesso, categorias).
3. Escreva `spikes/s1/install.ps1` (**exige administrador**): copia a DLL para `C:\Program Files\LocalCameraSpike\`, roda `regsvr32 /s`, e imprime o comando para criar a câmera (o executável do exemplo). Escreva `spikes/s1/uninstall.ps1` que desfaz tudo e remove a câmera.
4. Copie `docs/spikes/S1-modelo.md` (crie abaixo) para `docs/spikes/S1.md`.
   Conteúdo do modelo (crie o arquivo `docs/spikes/S1-modelo.md`):

### Parte do humano
5. Num terminal **como administrador**: `.\spikes\s1\install.ps1` e crie a câmera conforme o script indicar.
6. Para **cada app** da matriz: abra o app, selecione a câmera virtual (o exemplo da Microsoft mostra um padrão de teste) e preencha a linha.
7. No NVIDIA Broadcast: execute os 4 casos da tabela.
8. Se o Broadcast **não** listar a câmera MF: peça ao agente para preparar o **Plano B** (filtro DirectShow, biblioteca Softcam ou equivalente) e repita a matriz.
9. Responda ao agente com a tabela preenchida (cole o texto) e o veredito.

### De volta ao agente
10. Preencha `docs/spikes/S1.md` com os resultados, crie `docs/adr/0002-camera-virtual.md` (status **aceito**) com a decisão e as consequências para a Fase 4 (qual API, se precisa de assinatura, se o plano B entra).

## Não faça

- Não declare "funciona" sem o humano ter visto a imagem no app.
- Não deixe a câmera de teste instalada ao final (`uninstall.ps1`).
- Não coloque código do spike em `desktop/` nem `virtualcam/`.
