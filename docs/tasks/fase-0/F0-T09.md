## Passos
1. Instale as dependências de teste (em cada pacote que existir):
   ```powershell
   foreach ($p in 'packages/shared','desktop','mobile') {
     if (Test-Path "$p/package.json") {
       pnpm --filter ./$p add -D vitest jsdom @vitejs/plugin-react @testing-library/react @testing-library/user-event @testing-library/jest-dom
     }
   }
   ```
2. `vitest.config.ts` (em cada pacote; nos apps acrescente o alias `@` → `./src`):
   ```ts
   import { defineConfig } from "vitest/config";
   import react from "@vitejs/plugin-react";

   export default defineConfig({
     plugins: [react()],
     test: {
       environment: "jsdom",
       globals: true,
       setupFiles: ["./src/test/setup.ts"],
       css: false,
     },
   });
   ```
3. `src/test/setup.ts`: `import "@testing-library/jest-dom/vitest";`
4. Scripts: em cada `package.json` → `"test": "vitest run --passWithNoTests"`. Em `packages/shared`, adicione ao `exports`: `"./test": "./src/test/render.tsx"`.
5. `packages/shared/src/test/render.tsx`:
   ```tsx
   import type { ReactElement } from "react";
   import { render } from "@testing-library/react";
   import { I18nextProvider } from "react-i18next";
   import { createI18n, type AppLanguage } from "../i18n";

   export async function renderWithProviders(ui: ReactElement, lng: AppLanguage = "pt-BR") {
     const i18n = await createI18n(lng);
     return render(<I18nextProvider i18n={i18n}>{ui}</I18nextProvider>);
   }
   ```
   (Instale `@testing-library/react` como dependência de `packages/shared` se o tipo não resolver.)
6. Escreva os testes:
   - **UT-0.01** `cn.test.ts`: `cn("p-2","p-4")` → `"p-4"`; `cn("a", false && "b", "c")` → `"a c"`; `cn("text-red-500","text-blue-500")` → `"text-blue-500"`.
   - **UT-0.02** `tailwind-preset.test.ts`: importa `tokens` e o preset; confere `tokens.accent === "#22D3EE"`, `tokens.bg === "#070B14"`, `tokens.danger === "#F43F5E"`; confere que o preset tem `theme.extend.boxShadow` com as chaves `glass`, `overlay`, `glow-accent` e `borderRadius.xl === "24px"`.
   - **UT-0.03** `parity.test.ts`: função `flatten(obj, prefix="")` que devolve o conjunto de chaves-folha; `expect(flatten(ptBR)).toEqual(flatten(en))` (compare como conjuntos ordenados). Inclua um segundo teste que prova que a função detecta diferença (compare com um objeto sem uma chave e espere que **não** sejam iguais).
   - **UT-0.04** `lint-rule.test.ts` (primeira linha: `// @vitest-environment node`):
     ```ts
     import { ESLint } from "eslint";
     import path from "node:path";
     import { it, expect } from "vitest";

     const root = path.resolve(__dirname, "../../../..");

     it("UT-0.04: texto fixo em JSX é reprovado pelo lint", async () => {
       const eslint = new ESLint({ cwd: root, overrideConfigFile: path.join(root, "eslint.config.js") });
       const code = "export const A = () => <div>Texto fixo</div>;\n";
       const [res] = await eslint.lintText(code, { filePath: path.join(root, "desktop/src/__fixture__.tsx") });
       expect(res.messages.some((m) => m.ruleId === "i18next/no-literal-string")).toBe(true);
     });
     ```
     Ajuste o caminho `root` conforme a profundidade real do arquivo. Se `eslint` não resolver, adicione `eslint` como devDependency de `packages/shared`.
7. Um teste "de exemplo" em cada app (`desktop/src/App.test.tsx`, `mobile/src/App.test.tsx`): renderiza `<App />` com `renderWithProviders` e confere que o botão de teste aparece (use o texto pt-BR da chave `smoke`). Se o app não existir ainda, pule e anote.
