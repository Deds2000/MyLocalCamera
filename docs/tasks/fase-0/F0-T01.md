## Passos
1. Verifique as ferramentas e anote as versões:
   ```powershell
   node -v ; pnpm -v ; git --version
   ```
   Se `pnpm` não existir: `corepack enable` e depois `corepack prepare pnpm@latest --activate`.
2. Se ainda não é um repositório: `git init -b main`.
3. Crie as pastas listadas com um arquivo `.gitkeep` em cada.
4. `pnpm-workspace.yaml`:
   ```yaml
   packages:
     - "desktop"
     - "mobile"
     - "packages/*"
   ```
5. `package.json` da raiz (substitua `<PNPM>` pela saída de `pnpm -v` e `<NODE_MAJOR>` pelo major de `node -v`):
   ```json
   {
     "name": "localcamera",
     "private": true,
     "version": "0.0.0",
     "packageManager": "pnpm@<PNPM>",
     "engines": { "node": ">=<NODE_MAJOR>" },
     "scripts": {
       "lint": "pnpm -r --if-present lint",
       "typecheck": "pnpm -r --if-present typecheck",
       "test": "pnpm -r --if-present test",
       "ci": "powershell -NoProfile -ExecutionPolicy Bypass -File scripts/ci.ps1",
       "prepare": "git config core.hooksPath .githooks"
     }
   }
   ```
6. `.nvmrc`: apenas o número do major do Node (ex.: `22`).
7. `tsconfig.base.json`:
   ```json
   {
     "compilerOptions": {
       "target": "ES2022",
       "lib": ["ES2022", "DOM", "DOM.Iterable"],
       "module": "ESNext",
       "moduleResolution": "Bundler",
       "strict": true,
       "noUncheckedIndexedAccess": true,
       "noImplicitOverride": true,
       "exactOptionalPropertyTypes": false,
       "resolveJsonModule": true,
       "isolatedModules": true,
       "skipLibCheck": true,
       "jsx": "react-jsx",
       "esModuleInterop": true,
       "forceConsistentCasingInFileNames": true
     }
   }
   ```
8. `.editorconfig`: `root = true`; `[*]` com `charset = utf-8`, `end_of_line = lf`, `indent_style = space`, `indent_size = 2`, `insert_final_newline = true`, `trim_trailing_whitespace = true`; `[*.rs]` e `[*.kt]` com `indent_size = 4`; `[*.ps1]` com `end_of_line = crlf`.
9. `.gitattributes`:
   ```
   * text=auto eol=lf
   *.ps1 text eol=crlf
   .githooks/* text eol=lf
   *.png binary
   *.ico binary
   *.jar binary
   ```
10. `.gitignore`: `node_modules/`, `dist/`, `target/`, `fixtures/*` (mas **não** `fixtures/.gitkeep`), `*.log`, `.env*`, `desktop/src-tauri/target/`, `mobile/android/.gradle/`, `mobile/android/app/build/`, `mobile/android/build/`, `mobile/android/local.properties`, `.idea/`, `.vscode/*` (exceto `.vscode/extensions.json`), `docs/spikes/tmp/`, `spikes/**/build/`.
11. `LICENSE`: texto padrão da licença MIT, ano atual, titular "LocalCamera contributors".
12. `README.md`: título, uma frase do projeto, e uma seção "Desenvolvimento" com `pnpm install` e `pnpm run ci` (completar nas fases seguintes).
13. Dependências de lint/formatação (na raiz, `-w`):
    ```powershell
    pnpm add -Dw typescript eslint @eslint/js typescript-eslint globals eslint-plugin-react-hooks eslint-plugin-react-refresh eslint-plugin-i18next prettier eslint-config-prettier
    ```
14. `.prettierrc.json`: `{ "semi": true, "singleQuote": false, "trailingComma": "all", "printWidth": 100 }`. `.prettierignore`: `node_modules`, `dist`, `target`, `pnpm-lock.yaml`, `fixtures`, `mobile/android`.
15. `eslint.config.js` (config plana). Esqueleto — **consulte o README de `eslint-plugin-i18next` instalado** (`node_modules/eslint-plugin-i18next/README.md`) para o nome exato da config "flat":
    ```js
    import js from "@eslint/js";
    import tseslint from "typescript-eslint";
    import globals from "globals";
    import reactHooks from "eslint-plugin-react-hooks";
    import reactRefresh from "eslint-plugin-react-refresh";
    import i18next from "eslint-plugin-i18next";
    import prettier from "eslint-config-prettier";

    export default tseslint.config(
      { ignores: ["**/dist/**", "**/node_modules/**", "**/target/**", "mobile/android/**", "desktop/src-tauri/**", "fixtures/**"] },
      js.configs.recommended,
      ...tseslint.configs.recommended,
      { languageOptions: { globals: { ...globals.browser, ...globals.node } } },
      {
        files: ["desktop/src/**/*.{ts,tsx}", "mobile/src/**/*.{ts,tsx}"],
        plugins: { "react-hooks": reactHooks, "react-refresh": reactRefresh, i18next },
        rules: {
          ...reactHooks.configs.recommended.rules,
          "react-refresh/only-export-components": ["warn", { allowConstantExport: true }],
          "i18next/no-literal-string": ["error", { mode: "jsx-text-only" }],
        },
      },
      {
        files: ["**/*.test.{ts,tsx}", "**/*.spec.{ts,tsx}", "**/test/**", "**/catalog/**"],
        rules: { "i18next/no-literal-string": "off" },
      },
      prettier,
    );
    ```
    Ajuste só o necessário para o ESLint rodar sem erro de configuração.
16. Crie `docs/` vazio apenas se não existir (o conteúdo vem do pacote de documentos).
17. `pnpm install` e verifique.
