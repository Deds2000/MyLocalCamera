# F0-T14 — Relatórios de teste (`scripts/new-report.ps1`)

**Fase:** 0 · **Executor:** agente · **Depende de:** F0-T07 · **Tempo:** ~45 min · **Contexto estimado:** ~4k tokens

## Objetivo
Um comando que cria `docs/tests/fase-N.md` a partir do template, já preenchendo data, commit e informações do PC.

## Leia só isto
`docs/tests/_template.md` (abra para ver os campos).

## Arquivos
| Ação | Caminho |
|---|---|
| criar | `scripts/new-report.ps1` |

## Passos
1. Crie `scripts/new-report.ps1`:
   ```powershell
   param([Parameter(Mandatory)][int]$Phase)
   $ErrorActionPreference = 'Stop'
   Set-Location (Split-Path $PSScriptRoot -Parent)
   $dest = "docs/tests/fase-$Phase.md"
   if (Test-Path $dest) { throw "$dest já existe" }
   $text = Get-Content docs/tests/_template.md -Raw
   $text = $text -replace 'Fase N', "Fase $Phase" -replace 'N\.(\d\d)', "$Phase.`$1"
   $text = $text -replace 'AAAA-MM-DD', (Get-Date -Format 'yyyy-MM-dd')
   $commit = (git rev-parse --short HEAD) 2>$null
   $cpu = (Get-CimInstance Win32_Processor | Select-Object -First 1).Name
   $gpu = (Get-CimInstance Win32_VideoController | Select-Object -ExpandProperty Name) -join ' / '
   $ramGb = [math]::Round((Get-CimInstance Win32_ComputerSystem).TotalPhysicalMemory / 1GB)
   $os = (Get-CimInstance Win32_OperatingSystem)
   $info = "$cpu · $gpu · ${ramGb} GB · Windows $($os.Version)"
   $text = $text -replace '\| Commit / tag \| \|', "| Commit / tag | $commit |"
   $text = $text -replace '\| PC \(CPU · GPU · RAM · Windows build\) \| \|', "| PC (CPU · GPU · RAM · Windows build) | $info |"
   Set-Content -Path $dest -Value $text -Encoding utf8
   Write-Host "Criado $dest"
   ```
2. Teste: `.\scripts\new-report.ps1 -Phase 99`, abra `docs/tests/fase-99.md`, confira os campos preenchidos e **apague** o arquivo de teste.
