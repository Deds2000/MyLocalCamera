## Passos
1. Anote a versão: `rustc -V` e `cargo -V`.
2. `rust-toolchain.toml` (use o número de versão que `rustc -V` mostrou, ex.: `1.8x.y`):
   ```toml
   [toolchain]
   channel = "<versão do rustc -V>"
   components = ["rustfmt", "clippy"]
   profile = "minimal"
   ```
3. `Cargo.toml` da raiz:
   ```toml
   [workspace]
   resolver = "2"
   members = ["crates/lc-protocol", "tools/mock-sender", "desktop/src-tauri"]

   [workspace.package]
   edition = "2021"
   license = "MIT"
   version = "0.0.0"
   ```
4. Crie as crates:
   ```powershell
   cargo new crates/lc-protocol --lib --vcs none
   cargo new tools/mock-sender --bin --vcs none
   ```
   Em cada `Cargo.toml` gerado, troque `edition`/`license`/`version` por `edition.workspace = true`, `license.workspace = true`, `version.workspace = true`.
5. `rustfmt.toml`: `max_width = 100` e `edition = "2021"`.
6. **Se `desktop/src-tauri` ainda não existir** (F0-T02 não feito), remova-a de `members` por enquanto e registre em `PROGRESS.md` que deve ser adicionada depois.
7. `deny.toml` (opcional): rode `cargo install cargo-deny` só se o usuário aprovar; caso contrário, pule e anote em Observações.
8. Rode formatação e checagens.
