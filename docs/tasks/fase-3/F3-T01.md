## Passos
1. Adicionar `tauri-plugin-single-instance`; no callback de 2ª instância: `show()` + `set_focus()` da janela existente.
2. `window.rs`: `WindowState { w, h, x, y, maximized }` lido/gravado em `<data_dir>/window.json` (app data dir do Tauri). JSON corrompido/ausente → padrão 1280×800 centralizado, **sem panic** (FT-3.09). Validar: a posição salva deve intersectar um monitor de `available_monitors()`; se não → centralizar no 1º monitor.
3. Salvar estado no `CloseRequested` e em maximize/restore (listener no evento da janela).
4. `Shell.tsx`: grade `grid-rows-[40px_1fr_32px]`; linha do meio: preview (flex, `bg-raised`, 16:9 centralizado) + painel (largura por `panelWidth(w)` via resize listener). Breakpoints por largura da **janela**.
5. `Titlebar.tsx`: div com `data-tauri-drag-region` (arrasto nativo; duplo clique → `maximize()/unmaximize()`); pílula placeholder ("Desconectado" via `common.state.idle`); menu de idioma (`DropdownMenu`: Sistema/Português/English; `i18next.changeLanguage`; persistir em `localStorage("lang")` — o slice `settings` da F3-T14a migra isso, não recriar); botões de janela via `@tauri-apps/api/window`.
6. Atualizar `App.tsx`/`App.test.tsx`.
7. i18n: se as chaves da titlebar (ex.: "Sistema/System", aria-labels dos botões) **não** existirem em `docs/ui/copy.md`, registrá-las lá primeiro e adicionar aos dois JSONs (a F3-T14b copia o resto; não duplicar trabalho).
