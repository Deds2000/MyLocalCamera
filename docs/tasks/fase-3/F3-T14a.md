# F3-T14a — Store (zustand) com seletores estreitos

**Fase:** 3 · **Executor:** agente · **Depende de:** F3-T13 · **Tempo:** ~2.5 h · **Contexto estimado:** ~10k tokens

## Objetivo
Store global com `zustand` e os slices `connection`, `cameraState`, `stats`, `trust`, `usb`, `health`, `settings`, `ui`, com seletores estreitos, ações que chamam `invoke` e **só confirmam** quando o evento correspondente volta, e subscrição única dos eventos Tauri.

## Leia só isto
Só este cartão + `desktop/src/lib/tauri.ts` (tipos da F3-T13).

## Contexto embutido
`ui/desktop.md` §2.11 — slices do store:

| Slice | Conteúdo | Atualizado por |
|---|---|---|
| `connection` | estado (`waiting`/`pairing`/`connected`/`reconnecting`/`error`), aparelho, transporte, códigos de erro | `session://connection` |
| `cameraState` | espelho do `STATE` do celular (`rev`, `camera`, `video`, `presentation`, `audio`) + otimismo pendente | `session://state` + ações da UI |
| `stats` | fps, bitrate, RTT, descartes | `session://stats` (≤ 2 Hz) |
| `trust` | pedido pendente, lista de confiáveis | `trust://pending`, comandos |
| `usb` | aparelhos ADB | `adb://devices` (Fase 5 — slice **vazio** por agora) |
| `health` | cinco indicadores | `health://changed` (F3-T12) + `get_health` |
| `settings` | preferências persistidas (idioma, aba ativa, interface de rede) | comandos de settings |
| `ui` | aba ativa, tela cheia, diálogos abertos, **mirror/rotação do usuário** (aplicados localmente no PC — F3-T11) | local |

Regras:
- Ações da UI chamam `invoke` e **só confirmam** quando o evento correspondente volta (ex.: `approve` → fechar o diálogo no `session://connection` conectado, não na resolve do comando).
- `ui-spec.md` §4: **seletores estreitos** — cada componente assina só o pedaço de que precisa; nada de `setState` por quadro (frames não passam pelo store).
- **Migrar** o idioma persistido em `localStorage("lang")` (F3-T01) para o slice `settings` e remover o `localStorage` do Titlebar.
- `cameraState`/otimistas com `rev`: a reconciliação por `rev` de controles de câmera é Fase 6 — neste cartão, o slice guarda o espelho e a flag `pending`; não implementar otimistas.
- `stats`: **sem** nível de áudio (Fase 8).

## Passos
1. Instalar `zustand`.
2. Criar os slices (ações usam `lib/tauri.ts`; erros de `invoke` viram estado `error` com código, não exceção solta).
3. `useTauriEvents.ts`: um hook chamado **uma vez** no App que assina `session://connection`, `session://stats`, `trust://pending` (e, quando existir, `health://changed`) e aplica nos slices.
4. Mover a persistência do idioma para `settings` (remover `localStorage` do Titlebar; a chave do idioma usa i18next `changeLanguage` em tempo real).
5. Seletores estreitos exportados (ex.: `selectStats`, `selectConnectionState`, `selectTrustPending`, ...) — componentes usam só eles.
