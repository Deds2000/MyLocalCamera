# F3-T04 — Estado vazio e aba Conexão (QR)

**Fase:** 3 · **Executor:** agente · **Depende de:** F3-T02, F3-T14b, F3-T14a · **Tempo:** ~3 h · **Contexto estimado:** ~13k tokens

## Objetivo
Estado `empty` da área de preview (`EmptyState` com QR, wireframe §2.3) e a aba **Conexão** do painel: seção "Parear novo aparelho" (`QRCard` + seletor de interface + **Regenerar QR** com confirmação + código mascarado com mostrar/copiar), seção "Aparelhos USB" (estrutura pronta, dados na Fase 5) e seção "Dispositivos confiáveis" (estrutura; conteúdo na F3-T06).

## Leia só isto
Só este cartão + `docs/ui/copy.md` seções `desktop` (chaves `desktop.empty.*`, `desktop.connection.*`) + `desktop/src/lib/tauri.ts` (tipos da F3-T13).

## Contexto embutido
Wireframe §2.3 (estado vazio): preview mostra `EmptyState` — "Conecte seu celular" / "Escaneie o QR code com o app LocalCamera ou plugue o cabo USB", QR central, legenda "Rede: {ip} · Porta {port}", botão **Regenerar QR** (↻), separador "ou use o cabo USB" + dica de depuração USB.

Seção "Parear novo aparelho" (§2.6.1; recolhida quando já há celular conectado):

| Elemento | Detalhe |
|---|---|
| `QRCard` | QR 220 px com margem clara; legenda "Rede: {ip} · Porta {port}" |
| Seletor de interface | aparece se houver > 1 IP; `Select` com nome da interface + IP; muda o QR |
| **Regenerar QR** | botão secundário; abre `AlertDialog` com `desktop.connection.regenerateConfirm` ("Regenerar o código invalida o QR atual. Aparelhos já pareados continuam funcionando.") |
| Código de pareamento | campo somente leitura **mascarado** (••••), botões mostrar/ocultar e copiar (toast "Copiado!") |

URI de pareamento (CHEATSHEET): `localcamera://connect?v=1&hosts=IP1,IP2&port=48650&token=<32 hex>&pc=<pcId>&name=<nome>`. O token rotaciona após cada pareamento e em "Regenerar". A UI **nunca** imprime o token em log/título (ST-3.04) — mostrar o código completo no campo de pareamento é o recurso de digitação manual (intencional da UI).

`DeviceCard` (§2.6.1; só quando conectado): ícone, nome, modelo, Android, chip do transporte (Wi-Fi/USB), RTT, botão **Desconectar** (secundário, sem confirmação) — neste cartão: estrutura que lê do slice `connection`; só aparece quando houver sessão.

Seção "Aparelhos USB": **estrutura** — `DeviceRow` por aparelho com badge de estado (a tabela de estados é da Fase 5) e vazio com "Ative a depuração USB no celular e plugue o cabo."; interruptor "Conectar automaticamente ao plugar" **desabilitado com tooltip** (Fase 5). Sem dados ADB (Fase 5).

Seção "Dispositivos confiáveis": estrutura com `DeviceRow` + vazio "Nenhum aparelho pareado." — o conteúdo/revogação é F3-T06.

Interfaces de rede: `get_connection_info` devolve `interfaces[]` com `isVirtual`. Regra de exibição: **adaptadores reais primeiro; virtuais óbvios escondidos por padrão** (Hyper-V/VMware/VPN/túneis — heurística por nome); escolha do usuário persiste (slice `settings`). Função pura em TS (testável).

## Passos
1. `interface-filter.ts`: `filterInterfaces(ifaces, userChoice?) -> { shown, defaultIp }` (reais primeiro, virtuais escondidos por padrão, escolha do usuário vence).
2. `ConnectionTab`: seções na ordem (DeviceCard → Parear → USB → Confiáveis); parear recolhida quando `connection.state === connected`.
3. QR: URI vinda de `get_connection_info` (usar `effectivePort` — FT-3.08); trocar a interface → novo QR; **Regenerar QR** abre `AlertDialog` → só no **Confirmar** chama `regenerate_token` e atualiza o QR (cancelar não muda nada — UT-3.23).
4. Código mascarado: `pairCodeMasked` por padrão; "mostrar" revela o token no campo (recurso manual); copiar → `navigator.clipboard` + toast `common.actions.copied`.
5. `PreviewArea` estado `empty` conforme o wireframe (usa `QRCard`/`EmptyState`/`Button` da F3-T02; textos por chaves).
6. `DeviceCard` + `UsbList` (estrutura, dados ausentes → estados vazios).
7. AT-3.01 pelo agente: `pnpm --filter desktop tauri dev` em background; esperar a janela (UIA); screenshot (PowerShell `System.Drawing`); decodificar/ou comparar pixels do QR antes/depois do regenerate (URIs diferentes ⇒ QRs diferentes — comparar as imagens); sem tocar no mouse do usuário.
