`ui-spec.md` §1.7 (movimento, desktop/framer): durações `fast` 120 ms / `base` 200 ms / `slow` 320 ms; easing `cubic-bezier(0.22, 1, 0.36, 1)`; troca de seção do painel = fade + 8 px; cartões = fade + scale 0.98→1; diálogos = scale 0.96→1 + fade; mola `{ type: 'spring', stiffness: 300, damping: 30 }`; pulso "AO VIVO" = anel expandindo/esmaecendo 1,6 s infinito **só `transform`/`opacity`** (o preset já tem `animate-pulse-ring`); **`prefers-reduced-motion`**: só fade 0–80 ms, pulso estático.

Toasts: `Sonner`, canto **inferior esquerdo**, 4 s (erros 8 s com ação) — não usar toast para erro que bloqueia fluxo.

`ui-spec.md` §1.8 (estados interativos): hover +4% branco; pressionado `scale(0.98)`; foco teclado anel 2 px `accent` offset 2 px **sempre visível**; desabilitado opacidade 45% + **tooltip com o motivo**; carregando spinner no lugar do ícone.
