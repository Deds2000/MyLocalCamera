# F1-T04a — Servidor: crate `lc-server`, listener, limites e laço de leitura

**Fase:** 1 · **Executor:** agente · **Depende de:** F1-T02b · **Tempo:** ~3 h · **Contexto estimado:** ~11k tokens

## Objetivo
Criar a crate `lc-server` (lógica de rede do desktop, **independente do Tauri**) com: listener TCP (porta de *fallback*), limite de conexões não autenticadas, timeout do primeiro quadro, laço de leitura com `FrameReader` e tratamento de erros de protocolo. O handshake vem no F1-T04b.

## Leia só isto
`docs/CHEATSHEET.md` (portas, limites e tempos). Nada mais.

## Contexto embutido
- Padrão: `0.0.0.0:48650`. Se a porta estiver **ocupada**, escolher uma livre (porta 0) e **avisar** com evento (`PortChanged`).
- Conexões **não autenticadas**: no máximo **8** ao mesmo tempo; a 9ª é fechada imediatamente. O primeiro quadro (`HELLO`) deve chegar em **5 s**, senão fecha.
- Erro do leitor (`BadMagic`, `TooLarge`) → fechar a conexão com motivo `protocol_error`. **Nunca** panic.
- Cada conexão tem `conn_id: u64` crescente. `TCP_NODELAY` ligado.
- A crate fica em `crates/lc-server` e será usada por `desktop/src-tauri`.

## Passos
1. `cargo new crates/lc-server --lib --vcs none`; use `*.workspace = true`; adicione ao workspace. Dependências:
   ```powershell
   cargo add -p lc-server tokio --features rt-multi-thread,macros,net,io-util,sync,time
   cargo add -p lc-server tracing thiserror bytes
   cargo add -p lc-server lc-protocol --path crates/lc-protocol
   cargo add -p lc-server --dev lc-testkit --path crates/lc-testkit
   cargo add -p lc-server --dev tokio --features test-util
   ```
2. `config.rs`:
   ```rust
   pub struct ServerConfig {
       pub bind_ip: std::net::IpAddr,          // 0.0.0.0 em produção, 127.0.0.1 em testes
       pub port: u16,                           // 48650; 0 = qualquer
       pub data_dir: std::path::PathBuf,
       pub pc_name: String,
       pub app_version: String,
       pub max_unauth_conns: usize,             // 8
       pub hello_timeout: std::time::Duration,  // 5 s
   }
   impl ServerConfig { pub fn for_tests(dir: std::path::PathBuf) -> Self { /* 127.0.0.1, porta 0, hello_timeout 300 ms */ } }
   ```
3. `events.rs`:
   ```rust
   #[derive(Debug, Clone, PartialEq, Eq)]
   pub enum CloseReason { PeerClosed, HelloTimeout, ProtocolError, TooManyUnauth, Shutdown, Replaced, ConnectionLost }
   #[derive(Debug, Clone)]
   pub enum ServerEvent {
       Listening { port: u16 },
       PortChanged { requested: u16, actual: u16 },
       ConnectionOpened { conn_id: u64, peer: std::net::SocketAddr },
       ConnectionClosed { conn_id: u64, reason: CloseReason },
   }
   ```
4. `state.rs`: `enum ConnState { AwaitHello, Authenticating, Pending, Active, Closing }` e `fn transition(from: ConnState, to: ConnState) -> Result<ConnState, InvalidTransition>` com a tabela de transições válidas: `AwaitHello→Authenticating`, `Authenticating→Pending`, `Authenticating→Active`, `Pending→Active`, qualquer→`Closing`; todas as outras **inválidas**.
5. `lib.rs`:
   ```rust
   pub struct ServerHandle { /* shutdown tx, join handle, port */ }
   impl ServerHandle {
       pub fn local_port(&self) -> u16;
       pub fn events(&mut self) -> &mut tokio::sync::mpsc::Receiver<ServerEvent>;
       pub async fn shutdown(self);
   }
   pub async fn start(cfg: ServerConfig) -> Result<ServerHandle, ServerError>;
   ```
   `start`: `TcpListener::bind((ip, port))`; se `AddrInUse` e `port != 0`, `bind((ip, 0))` e emitir `PortChanged`; emitir `Listening`; lançar o *accept loop* numa task.
6. `conn.rs` — esqueleto do laço por conexão:
   ```rust
   // recebe: stream, conn_id, permit (SemaphorePermit do limite de não autenticadas), events_tx, cfg
   // 1. set_nodelay(true)
   // 2. loop com tokio::select! { leitura de bytes, timeout do hello (apenas enquanto AwaitHello), sinal de shutdown }
   // 3. reader.push(&buf[..n]) -> frames; Err(_) => fechar com ProtocolError
   // 4. neste cartão: ao receber o 1º frame, apenas logar o tipo e manter a conexão (o handshake real é F1-T04b)
   // 5. ao sair: emitir ConnectionClosed { reason }; o permit é liberado automaticamente ao dropar
   ```
   **Atenção:** nunca perder bytes ao cancelar uma leitura — use `read(&mut buf).await` dentro de `select!` (cancel-safe) e **alimente o `FrameReader`** com o que foi lido.
7. Limite de não autenticadas: `Arc<Semaphore>` com `max_unauth_conns`; no accept, `try_acquire_owned()`; se falhar, feche o socket na hora e emita `ConnectionClosed{TooManyUnauth}` (sem criar task).

- Não prenda o `Semaphore` permit depois de autenticar (o F1-T04b o libera).
- Não escute em `0.0.0.0` nos testes (use `127.0.0.1`).
