# F1-T02a — `lc-protocol`: cabeçalho e `FrameReader`

**Fase:** 1 · **Executor:** agente · **Depende de:** F1-T01 · **Tempo:** ~3 h · **Contexto estimado:** ~11k tokens

## Objetivo
Implementar em Rust o **leitor incremental de quadros** (aceita bytes fragmentados) e o escritor de quadros, passando em **todos** os vetores de `frames` e nos testes de propriedade.

## Leia só isto
`docs/CHEATSHEET.md` (cabeçalho e limites). O arquivo `docs/protocol-vectors.json` (parte `frames`).

## Contexto embutido
- Cabeçalho = 18 bytes (magic `0x4C43` LE, type, flags, stream, reserved, pts u64 LE, length u32 LE).
- Limite de payload padrão = `8 * 1024 * 1024`. **Valide `length` antes de reservar memória.**
- Tipo desconhecido **não** é erro no leitor: o quadro é entregue com o `msg_type` bruto (quem interpreta é a camada `Message`, F1-T02b).
- Depois de um erro (`BadMagic`/`TooLarge`) o leitor fica **envenenado**: novas chamadas a `push` devolvem o mesmo erro (o chamador deve fechar a conexão).

## Passos
1. Dependências:
   ```powershell
   cargo add -p lc-protocol bytes thiserror
   cargo add -p lc-protocol --dev serde --features derive
   cargo add -p lc-protocol --dev serde_json hex
   ```
2. `types.rs`: constantes de tipo (`pub mod msg { pub const HELLO: u8 = 0x01; ... }` com **todos** os tipos da tabela do CHEATSHEET), `pub fn type_name(code: u8) -> &'static str` (nomes em MAIÚSCULAS iguais aos do CHEATSHEET, `"UNKNOWN"` para outros), constantes `MAGIC`, `HEADER_LEN`, `MAX_PAYLOAD`, e `pub mod flags { pub const KEYFRAME: u8 = 1; pub const HAS_PARAMS: u8 = 2; }`.
3. `error.rs`:
   ```rust
   #[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
   pub enum ProtocolError {
       #[error("magic inválido")]
       BadMagic,
       #[error("payload grande demais: {0} bytes")]
       TooLarge(u32),
       #[error("json inválido: {0}")]
       BadJson(String),
       #[error("mensagem inválida: {0}")]
       Invalid(String),
   }
   ```
4. `frame.rs` — esqueleto:
   ```rust
   use bytes::{Bytes, BytesMut, Buf};
   use crate::{error::ProtocolError, types::*};

   #[derive(Debug, Clone, PartialEq, Eq)]
   pub struct Frame {
       pub msg_type: u8,
       pub flags: u8,
       pub stream: u8,
       pub pts_us: u64,
       pub payload: Bytes,
   }

   pub struct FrameReader {
       buf: BytesMut,
       max_payload: u32,
       poisoned: Option<ProtocolError>,
   }

   impl FrameReader {
       pub fn new() -> Self { Self::with_max_payload(MAX_PAYLOAD) }
       pub fn with_max_payload(max_payload: u32) -> Self { /* ... */ }
       /// Bytes ainda não consumidos (cabeçalho/payload incompletos).
       pub fn pending_len(&self) -> usize { self.buf.len() }
       /// Alimenta bytes e devolve todos os quadros completos.
       pub fn push(&mut self, data: &[u8]) -> Result<Vec<Frame>, ProtocolError> {
           // 1. se envenenado -> Err(clone)
           // 2. self.buf.extend_from_slice(data)
           // 3. loop: se buf.len() < HEADER_LEN -> break
           //    lê magic (u16 LE) sem consumir; != MAGIC -> envenena e Err(BadMagic)
           //    lê length (u32 LE em offset 14); > max_payload -> envenena e Err(TooLarge(length))
           //    se buf.len() < HEADER_LEN + length -> break (espera mais bytes)
           //    consome o cabeçalho, extrai payload (split_to(length).freeze()), monta Frame, push
           // 4. Ok(frames)
       }
   }

   /// Serializa um quadro. Erro se payload > MAX_PAYLOAD.
   pub fn encode_frame(msg_type: u8, flags: u8, stream: u8, pts_us: u64, payload: &[u8])
       -> Result<Vec<u8>, ProtocolError> { /* ... */ }
   ```
   Use `u16::from_le_bytes`, `u64::from_le_bytes` etc. sobre fatias do buffer (sem `unwrap()` em caminho de produção: use `try_into().expect("slice de tamanho fixo")` apenas com tamanho garantido, comentando o invariante).
5. `lib.rs`: reexporte `Frame`, `FrameReader`, `encode_frame`, `ProtocolError`, `msg`, `type_name`, `flags`.
6. `tests/vectors.rs`: carregue `../../docs/protocol-vectors.json` (caminho relativo ao `CARGO_MANIFEST_DIR`). Para cada vetor de `frames`, execute **3 modos de entrega** e compare com `expect`:
   - inteiro (um `push`);
   - **byte a byte**;
   - **todas as divisões em 2 partes** (`for i in 1..len`).
   Comparação: se `expect.error` existe, o resultado final deve ser `Err` cujo `Debug` **começa** com o nome (`BadMagic`/`TooLarge`); senão, a lista de quadros (tipo, flags, stream, pts como `u64` parseado da string, payload em hex) deve ser **igual** à esperada e `pending_len()` = `pendingBytes`. (No modo com erro, basta o erro aparecer em algum `push`.)
7. Testes unitários em `frame.rs` (`#[cfg(test)]`): `encode_frame` + `FrameReader` (ida e volta com pts 0 e `u64::MAX`, payload vazio), payload acima do limite no `encode_frame` → `TooLarge`, leitor envenenado continua devolvendo o erro.
8. Testes de propriedade (`proptest`) — **UT-1.20/1.21**:
   - gere sequências de 0–20 quadros válidos (tipos/flags/stream/pts/payload de até 2 KiB aleatórios), concatene os bytes, **particione aleatoriamente** em blocos (1..=64 bytes) e verifique que a lista de quadros lida **é igual** à original;
   - alimente bytes totalmente aleatórios (0–4 KiB): **nunca** deve dar `panic`, e `pending_len()` nunca excede `HEADER_LEN + max_payload` (use `with_max_payload(4096)` no teste).
