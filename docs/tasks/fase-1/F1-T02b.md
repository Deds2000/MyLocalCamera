# F1-T02b — `lc-protocol`: mensagens JSON (serde) e `Message`

**Fase:** 1 · **Executor:** agente · **Depende de:** F1-T02a · **Tempo:** ~3 h · **Contexto estimado:** ~11k tokens

## Objetivo
Definir as estruturas JSON do protocolo e o `enum Message` com conversão **de/para `Frame`**, tolerante a campos desconhecidos, passando nos vetores `json` e em testes de propriedade.

## Leia só isto
`docs/CHEATSHEET.md` (tipos, reasons, estado) e a parte `json` de `docs/protocol-vectors.json`.

## Contexto embutido
- JSON em **camelCase**. Campos desconhecidos são **ignorados** (não usar `deny_unknown_fields`). Campos opcionais com `#[serde(default)]`.
- `reason` desconhecido vira a variante `Other` (`#[serde(other)]`).
- `HELLO` com payload > 64 KiB → `ProtocolError::TooLarge`.
- `Message::Unknown { type_code, len }` para tipos não reconhecidos (a conexão **não** cai por isso).
- `SET` aceita **um** item `{key,value}` ou uma **lista** deles.

## Passos
1. Dependências: `cargo add -p lc-protocol serde --features derive` e `cargo add -p lc-protocol serde_json`.
2. `json.rs` — structs (todas `#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]` e `#[serde(rename_all = "camelCase")]`):
   - `ProtocolVersion { major: u16, minor: u16 }`
   - `AppInfo { version: String, platform: String }`
   - `DeviceInfo { id: String, name: String, #[serde(default)] model: String, #[serde(default)] android_api: u32 }`
   - `Auth` = enum com `#[serde(tag = "kind", rename_all = "lowercase")]`: `Pair { token: String }`, `Device { device_id: String, key: String }` (com `#[serde(rename = "deviceId")]` no campo)
   - `CameraMode { w: u32, h: u32, fps: Vec<u32> }`, `CameraCaps { id: String, facing: String, modes: Vec<CameraMode> }`
   - `Caps { #[serde(default)] cameras: Vec<CameraCaps>, #[serde(default)] concurrent: bool, #[serde(default)] concurrent_modes: Vec<CameraMode>, #[serde(default)] audio: bool, #[serde(default)] codecs: Vec<String> }` (`Default` derivado)
   - `Hello { protocol, app, device, auth, #[serde(default)] caps: Caps }`
   - `Reason` = enum `#[serde(rename_all = "snake_case")]`: `BadToken, NotApproved, Revoked, Busy, VersionMismatch, BadAudioTicket, Timeout, ProtocolError`, e **última** variante `#[serde(other)] Other`
   - `PcInfo { id: String, name: String, app_version: String }`
   - `Welcome { accepted: bool, #[serde(default)] protocol: Option<ProtocolVersion>, #[serde(default)] session_id: Option<String>, #[serde(default)] audio_ticket: Option<String>, #[serde(default)] device_key: Option<String>, #[serde(default)] pc: Option<PcInfo>, #[serde(default)] reason: Option<Reason>, #[serde(default)] min_supported: Option<ProtocolVersion> }`
   - `AudioHello { session_id: String, ticket: String }`, `Pending { timeout_s: u32 }`, `AudioTicket { ticket: String }`
   - `StreamConfig { stream: u8, width: u32, height: u32, fps: u32, rotation_hint: u16, facing: String, #[serde(default)] profile: Option<String> }`
   - `SetItem { key: String, value: serde_json::Value }` e `SetPayload` com `#[serde(untagged)]`: `Many(Vec<SetItem>)`, `One(SetItem)` (**ordem:** `Many` primeiro)
   - `State { rev: u64, #[serde(default)] camera: CameraState, #[serde(default)] video: VideoState, #[serde(default)] presentation: Presentation, #[serde(default)] audio: AudioState }` — com sub-structs `CameraState { mode: String, active: String }`, `VideoState { width, height, fps: u32, bitrate_kbps: u32 }`, `Presentation { mirror: Sides<bool>, rotation: Sides<u16> }`, `Sides<T> { back: T, front: T }`, `AudioState { enabled: bool, gain: f32 }` (todos com `Default` e `#[serde(default)]`)
   - `Stats { recv_fps: f32, dropped: u32, queue_ms: u32 }`, `Bye { reason: String }`
3. `message.rs`:
   ```rust
   pub enum Message {
       Hello(Hello), Welcome(Welcome), AudioHello(AudioHello), Pending(Pending),
       AudioTicketRequest, AudioTicket(AudioTicket),
       Video { stream: u8, flags: u8, pts_us: u64, data: Bytes },
       Audio { pts_us: u64, data: Bytes },
       StreamConfig(StreamConfig), Set(SetPayload), State(State),
       Ping(u64), Pong(u64), Stats(Stats), RequestKeyframe { stream: u8 }, Bye(Bye),
       Unknown { type_code: u8, len: usize },
   }
   impl Message {
       pub fn from_frame(f: &Frame) -> Result<Message, ProtocolError>;
       /// Serializa em bytes de quadro prontos para enviar.
       pub fn encode(&self, pts_us: u64) -> Result<Vec<u8>, ProtocolError>;
   }
   ```
   Regras: `PING/PONG` exigem payload de **exatamente 8 bytes** (u64 LE), senão `Invalid`. `HELLO` > 65 536 bytes → `TooLarge`. JSON malformado ou fora do esquema → `BadJson(msg)`. `Video` usa `stream`/`flags`/`pts` do quadro; `encode` de `Welcome/AudioHello/...` usa `stream = 0`; `Audio` usa `stream = 3`.
4. `lib.rs`: `pub mod json; pub mod message; pub use message::Message;`.
5. `tests/vectors_json.rs`: para cada item de `json` do arquivo de vetores, desserialize para o tipo indicado em `message` (`HELLO`, `WELCOME`, `STATE`, `SET`, `STREAM_CONFIG`, `AUDIO_HELLO`, `STATS`, `BYE`); `expect == "ok"` → `Ok` e **ida e volta** (serializar e desserializar de novo = igual); `expect == "BadJson"` → `Err`. Faça **via `Message::from_frame`** embrulhando o JSON em um `Frame` do tipo correto.
6. Testes unitários e de propriedade:
   - ida e volta de `Ping/Pong/Audio/RequestKeyframe/Bye` com valores aleatórios (`proptest`) — **UT-1.22**;
   - `reason` desconhecido → `Reason::Other` (**UT-1.09**);
   - campos extras aceitos (**UT-1.07**); campos obrigatórios ausentes/tipo errado → `BadJson` (**UT-1.08**);
   - `HELLO` de 65 537 bytes → `TooLarge`; `PING` com 7 bytes → `Invalid`;
   - tipo desconhecido (`0x99`) → `Message::Unknown` (**parte de UT-1.06**).
