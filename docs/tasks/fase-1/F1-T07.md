# F1-T07 — Janela de aprovação USB (15 s, localhost, uso único)

**Fase:** 1 · **Executor:** agente · **Depende de:** F1-T06 · **Tempo:** ~2 h · **Contexto estimado:** ~6k tokens

## Objetivo
Permitir que, quando o **usuário** inicia a conexão por USB (Fase 5), o primeiro pareamento vindo de `127.0.0.1` dentro de **15 s** seja aprovado **sem diálogo**. Aqui só a lógica e a integração com o handshake.

## Leia só isto
`docs/CHEATSHEET.md` (janela USB). Nada mais.

## Contexto embutido
- A janela abre por `ServerHandle::open_usb_window()` e dura **15 s** (relógio injetável).
- Vale **só** para peer em `127.0.0.1`/`::1` e **uma única vez** (o primeiro `HELLO` válido a consome).
- O **token de pareamento continua obrigatório** (o deep link USB o inclui).
- Resultado = `ApproveAlways` (o celular recebe `deviceKey`; o usuário pode revogar depois).
- Fora da janela, conexões de localhost seguem o fluxo normal (aprovação/chave).

## Passos
1. `usb_window.rs`:
   ```rust
   pub const USB_WINDOW_SECS: u64 = 15;
   pub struct UsbWindow { open_until: Option<u64> }
   impl UsbWindow {
       pub fn new() -> Self;
       pub fn open(&mut self, now: u64);                       // abre/reabre por 15 s
       pub fn try_consume(&mut self, peer: std::net::IpAddr, now: u64) -> bool;
       pub fn is_open(&self, now: u64) -> bool;
   }
   ```
   `try_consume`: `true` somente se aberta, não expirada e `peer.is_loopback()`; consome (fecha). Peer não-loopback **não** consome.
2. `ServerHandle::open_usb_window()` (usa o relógio do sistema em segundos Unix; internamente chama `open`).
3. `handshake.rs`: no ramo `Pair` com token válido, **antes** do pedido de aprovação: `if usb_window.try_consume(peer.ip(), now) { ApproveAlways }`.
4. Evento `ServerEvent::UsbWindowOpened` / `UsbWindowClosed { used: bool }` (para a UI da Fase 5).
