# F1-T10 — Keepalive, RTT e agregador de estatísticas (500 ms)

**Fase:** 1 · **Executor:** agente · **Depende de:** F1-T09b · **Tempo:** ~3 h · **Contexto estimado:** ~9k tokens

## Objetivo
O servidor envia `PING` periódicos, mede o RTT, detecta **conexão perdida** (sem `PONG` por 6 s) nos dois sockets e emite estatísticas agregadas **a cada 500 ms** (base dos 2 Hz da UI).

## Leia só isto
`docs/CHEATSHEET.md` (PING/PONG, limites). Nada mais.

## Contexto embutido
- `PING` a cada **2 s** em cada socket (payload `u64` = relógio monotônico em ms); o cliente devolve `PONG` com o **mesmo** valor.
- **Sem `PONG` por 6 s** → encerrar com `CloseReason::ConnectionLost` e emitir `SessionEnded`. (Qualquer outro tráfego **não** substitui o PONG.)
- RTT = `agora_ms - valor_do_pong`; mantenha média móvel exponencial (α = 0,3).
- Estatísticas a cada **500 ms**: por stream, quadros/s e bytes/s (diferenças dos contadores), blocos de áudio/s, RTT e totais acumulados.
- Valores configuráveis (testes usam pequenos): `ping_interval` (2 s), `liveness_timeout` (6 s), `stats_interval` (500 ms).

## Passos
1. `config.rs`: `ping_interval`, `liveness_timeout`, `stats_interval` (e `for_tests` com valores pequenos configuráveis).
2. `keepalive.rs`: struct `Keepalive { last_pong: Instant, rtt_ewma_ms: Option<f32> }` com `on_pong(sent_ms, now_ms)`, `is_dead(now) -> bool`. Dentro do laço de cada conexão ativa: `tokio::select!` com um `interval(ping_interval)` que envia `PING`, e verificação de `is_dead` → fechar.
3. `stats.rs` — **função pura** testável:
   ```rust
   #[derive(Clone, Copy, Default)]
   pub struct Snapshot { pub video_frames: [u64; 3], pub video_bytes: [u64; 3], pub audio_blocks: u64, pub audio_bytes: u64 }
   #[derive(Clone, Debug, PartialEq)]
   pub struct SessionStats { pub video_fps: [f32; 3], pub video_kbps: [f32; 3], pub audio_blocks_per_s: f32, pub rtt_ms: Option<f32>, pub totals: Snapshot }
   pub fn compute_stats(prev: &Snapshot, curr: &Snapshot, dt: Duration, rtt_ms: Option<f32>) -> SessionStats;
   ```
   (Índice 0 = stream 1, 1 = stream 2, 2 = reservado.) `dt = 0` → zeros (sem divisão por zero).
4. Task agregadora por sessão: a cada `stats_interval` lê os `SessionCounters`, chama `compute_stats` e emite `ServerEvent::Stats { session_id, stats }`. A task termina com a sessão.
5. Contabilização de vídeo: no laço da sessão, para cada `VIDEO` aceito: `video_frames[stream-1] += 1`, `video_bytes += payload.len()`, `keyframes` se `flags & 1`.
