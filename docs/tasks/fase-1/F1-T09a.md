# F1-T09a — Tickets de áudio (`TicketStore`, lógica pura)

**Fase:** 1 · **Executor:** agente · **Depende de:** F1-T05 · **Tempo:** ~1,5 h · **Contexto estimado:** ~6k tokens

## Objetivo
Implementar o armazenamento de **`audioTicket`** (uso único, validade de 10 s, preso ao `sessionId`) como módulo **puro e testável** com relógio injetado. O uso no socket de áudio vem no F1-T09b.

## Leia só isto
`docs/CHEATSHEET.md` (limites: ticket 128 bits, uso único, 10 s). Nada mais.

## Contexto embutido
- Ticket = 16 bytes aleatórios → 32 hex (use `trust::secrets::random_hex(16)`).
- Um ticket só vale para o `sessionId` para o qual foi emitido.
- `redeem` **consome** o ticket (segundo uso falha). Ticket expirado falha.
- Emitir um novo ticket para a mesma sessão (ex.: `AUDIO_TICKET_REQUEST`) **invalida** o anterior ainda não usado.
- Segredos nunca em log.

## Passos
1. `tickets.rs`:
   ```rust
   pub const TICKET_TTL_SECS: u64 = 10;

   #[derive(Debug, PartialEq, Eq)]
   pub enum RedeemError { Unknown, Expired, WrongSession }

   pub struct TicketStore { /* HashMap<String, Entry> + índice por sessão */ }
   impl TicketStore {
       pub fn new() -> Self;
       /// Emite um ticket para a sessão (invalida o anterior não usado da mesma sessão).
       pub fn issue(&mut self, session_id: &str, now: u64) -> String;
       /// Consome o ticket se válido.
       pub fn redeem(&mut self, session_id: &str, ticket: &str, now: u64) -> Result<(), RedeemError>;
       /// Remove tickets de uma sessão encerrada e os expirados.
       pub fn purge(&mut self, session_id: Option<&str>, now: u64);
   }
   ```
   Compare o ticket com `ct_eq`. Implemente `Debug` manual que **não** mostra tickets.
2. `mod.rs`: `pub mod tickets; pub use tickets::*;`.
