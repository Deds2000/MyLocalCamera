# F1-T11b — `mock-sender`: flags de falha (e testes AT/FT automatizados)

**Fase:** 1 · **Executor:** agente · **Depende de:** F1-T11a · **Tempo:** ~4 h · **Contexto estimado:** ~11k tokens

## Objetivo
Adicionar ao mock os **modos de falha determinísticos** e usá-los para automatizar os testes de aceitação e de falha do servidor.

## Leia só isto
`docs/testing.md` §4.1 (tabela de flags — só as marcadas "Fase 1"). Nada mais.

## Contexto embutido — flags desta fase
| Flag | Efeito |
|---|---|
| `--fragment N` | Todos os `write` saem em pedaços de **N bytes** (com `flush` entre eles) |
| `--bad-magic` | Primeiro quadro com `magic` errado |
| `--huge-length` | Primeiro quadro com `length = 8 MiB + 1` (só o cabeçalho) |
| `--bad-json` | `HELLO` com JSON inválido |
| `--unknown-type` | Insere um quadro de tipo `0x99` (3 bytes) **a cada 30 quadros** de vídeo |
| `--delay-hello MS` | Espera MS ms antes do `HELLO` |
| `--no-pong` | Não responde `PING` |
| `--drop-ping` | Descarta o 1º `PING` e responde os demais |
| `--slow KBPS` | Limita a vazão de escrita (token bucket) |
| `--stall MS@SEG` | Depois de SEG s, para de escrever por MS ms |
| `--kill-after SEG` | Fecha o socket de forma **abrupta** (sem `BYE`) depois de SEG s |
| `--reconnect N` | Conecta/envia 1 s/desconecta, N vezes (usa `--state-file`) |
| `--fake-version M.m` | Anuncia `protocol {major: M, minor: m}` |

## Passos
1. `faults.rs`: `pub struct Faults { fragment: Option<usize>, bad_magic: bool, huge_length: bool, bad_json: bool, unknown_type: bool, delay_hello: Option<Duration>, no_pong: bool, drop_ping: bool, slow_kbps: Option<u32>, stall: Option<(Duration, Duration)>, kill_after: Option<Duration>, reconnect: Option<u32>, fake_version: Option<(u16,u16)> }`.
2. **Camada de escrita:** um `FaultyWriter` que envolve a escrita do socket e aplica `fragment` (fatias + `flush`), `slow` (token bucket por tempo) e `stall` (dorme no intervalo). Todo envio do mock passa por ele.
3. Modos "primeiro quadro malicioso" (`bad_magic`, `huge_length`, `bad_json`): enviam o quadro malformado e, em seguida, **leem até o servidor fechar**, devolvendo `Summary.closed_by = Some("server")` e o tempo até o fechamento.
4. `--reconnect N`: laço de N sessões curtas (1 s) reutilizando o `--state-file`; `Summary` agrega as N.
5. `--kill-after`: `tokio::time::sleep` + `socket.shutdown`/drop **sem** enviar `BYE`.
6. Documente cada flag no README (uma linha).
