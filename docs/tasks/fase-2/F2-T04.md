# F2-T04 — `ProtocolCodec.kt` (leitor incremental, escritor, JSON)

**Fase:** 2 · **Executor:** A · **Depende de:** F1-GATE · **Tempo:** ~5 h · **Contexto estimado:** ~14k tokens

## Objetivo
O codec do protocolo em Kotlin, em `mobile/android/app/src/main/java/com/localcamera/app/protocol/`: leitor incremental (mesmo desenho do Rust: buffer + estados), escritor e JSON das mensagens — passando em **todos** os vetores de `docs/protocol-vectors.json`.

## Leia só isto
`docs/protocol-vectors.json` (8 vetores de frames + 24 de JSON — é a fonte dos formatos exatos). `docs/CHEATSHEET.md` (tabela do cabeçalho e dos tipos). Não abra o `protocol.md` inteiro.

## Contexto embutido
- Cabeçalho (18 bytes, little-endian): `43 4C` (magic) · `type` · `flags` (bit0 keyframe, bit1 SPS/PPS) · `stream` · `0` (reserved) · `ptsUs` (u64) · `length` (u32; máx 8 MiB = `0x00800000`). Acima = `TooLarge`. Magic errada = `BadMagic`.
- Tipos: HELLO 01 · WELCOME 02 · PENDING 04 · VIDEO 10 · STREAM_CONFIG 12 · SET 20 · STATE 21 · PING/PONG 30/31 (payload u64) · STATS 32 · REQUEST_KEYFRAME 40 (vazio) · BYE 7F. **Tipo desconhecido → pular usando `length`, logar e devolver como `UNKNOWN` (nunca derrubar a conexão)** — os vetores mostram o caso.
- Limites: payload ≤ 8 MiB; JSON do HELLO ≤ 64 KiB.
- JSON: use `org.json` (vem com o Android; para os testes JVM, adicione a dependência de **teste** `org.json:json` — versão atual, confirme na documentação oficial do artefato).
- Nos vetores, `ptsUs` do `expect` é **string decimal** (u64) — leia como `String`.
- A semântica de referência é a do Rust (`crates/lc-protocol/`), mas os vetores já definem o comportamento esperado — não traduza o Rust.

## Passos
1. `Frame.kt`: enum `MessageType` (código ↔ nome, `UNKNOWN`), `Frame(type, flags, stream, ptsUs: Long, payload: ByteArray)`, `CodecError` (`BadMagic`, `TooLarge`, `BadJson`).
2. `FrameReader.kt`: `fun feed(data: ByteArray): ReaderResult` — buffer interno; emite frames completos; resto fica pendente (`pendingBytes`).
3. `FrameWriter.kt`: `fun write(frame): ByteArray` (cabeçalho 18 bytes LE + payload); rejeita payload > 8 MiB.
4. `Messages.kt`: `decodeHello/decodeWelcome/decodePending/decodeState/decodeStreamConfig/decodeSet/decodeStats/decodeBye` + os codificadores inversos. Mesmos campos dos vetores; **ignorar** campos desconhecidos; campo obrigatório ausente = `BadJson`.
5. Teste de vetores: carregue `docs/protocol-vectors.json` (caminho relativo ao módulo: `../../../docs/protocol-vectors.json`; se não achar, falhe com a mensagem "rode a partir da raiz do repo"), rode frames (reader) e JSON (decode + encode de volta) comparando 1:1 com `expect`.
6. Teste de fragmentação (UT-2.02): para cada vetor de `frames`, alimente o reader **byte a byte** e em pedaços de todos os tamanhos 1..len → mesmos frames e `pendingBytes` finais.
7. Rode: `gradlew :app:testDebugUnitTest --tests "com.localcamera.app.protocol.*"`.
