# F2-T11 — `StateReducer.kt` (estado mínimo, `rev`, `STATE`)

**Fase:** 2 · **Executor:** A · **Depende de:** F2-T04 · **Tempo:** ~3 h · **Contexto estimado:** ~10k tokens

## Objetivo
O estado compartilhado (o celular é o dono): mínimo da Fase 2 (câmera traseira, single, 1080p30, 8 Mbps), contador `rev`, serialização/`STATE` enviado ao conectar, e aplicação de `SET` para as chaves conhecidas da fase.

## Leia só isto
`docs/protocol.md` §9 (estado compartilhado) — só a seção. `docs/protocol-vectors.json` (vetores `state_basic`, `set_single`, `set_list`).

## Contexto embutido
- Estado mínimo: `{"rev":1,"camera":{"mode":"single","active":"back"},"video":{"width":1920,"height":1080,"fps":30,"bitrateKbps":8000},"presentation":{"mirror":{"back":false,"front":false},"rotation":{"back":0,"front":0}},"audio":{"enabled":true,"gain":1.0}}`.
- `rev` começa em 1 e **incrementa** a cada mudança; `STATE` sai ao conectar (F2-T09 avisa `welcome`) e a cada mudança.
- `SET` (PC→cel): `{key,value}` ou lista de pares; aplicar as chaves da Fase 2 (`video.width/height/fps/bitrateKbps`, `camera.active`, `presentation.*`); chaves desconhecidas → ignorar com log (controle completo é Fase 6).
- JSON via `Messages` do F2-T04 (formato exato dos vetores).
