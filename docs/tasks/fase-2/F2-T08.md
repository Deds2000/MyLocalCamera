# F2-T08 — `VideoEncoder.kt` (MediaCodec H.264)

**Fase:** 2 · **Executor:** A+H · **Depende de:** F2-T07 · **Tempo:** ~5 h · **Contexto estimado:** ~14k tokens

## Objetivo
Encoder H.264 de hardware: 1080p30 CBR 8 Mbps, keyframe a cada 1 s, sem B-frames, prioridade de tempo real, SPS/PPS anexados a **cada** keyframe, `ptsUs` de relógio monotônico (o mesmo que o áudio usará na Fase 8), `requestKeyframe()` e `setBitrate()`.

## Leia só isto
`docs/CHEATSHEET.md` (Padrões + bits de `flags`). `docs/spikes/S3.md` (seção "Encoders e orientação" + veredito). `docs/protocol.md` §10 (vídeo, áudio e sincronia) — só a seção.

## Contexto embutido
- S3 (G781B): encoder `OMX.qcom.video.encoder.avc`; **não aceita `KEY_LOW_LATENCY`** (definir "quando suportado", com try/ignore); 1º keyframe em 0,7–1,1 s; sem B-frames.
- Configuração: `COLOR_FormatSurface`, CBR, 8 Mbps, `KEY_I_FRAME_INTERVAL = 1`, `KEY_PRIORITY` tempo real, 1920×1080 NV12, 30 fps; perfil High **com fallback** (Main → Baseline se o encoder rejeitar; logar o escolhido).
- Saída: o 1º buffer `BUFFER_FLAG_CODEC_CONFIG` = SPS/PPS (**não é vídeo — nunca enviar como `VIDEO`**): guardar. Alguns encoders ignoram `KEY_PREPEND_HEADER_TO_SYNC_FRAMES` (armadilha §6 da fase) → **confira** se cada keyframe carrega SPS+PPS; se não, anexe os bytes guardados antes do IDR.
- `flags` do quadro (protocolo): bit0 = keyframe (IDR), bit1 = payload contém SPS/PPS.
- `ptsUs`: relógio monotônico injetável (`clock: () -> Long`), mesmo relógio do áudio futuro.
- API: `requestKeyframe()` = `PARAMETER_KEY_REQUEST_SYNC_FRAME` (assíncrono); `setBitrate(kbps)` = `setParameters` assíncrono. Logar encoder, perfil e nível (diagnóstico).

## Esqueleto de código
```kotlin
class VideoEncoder(private val inputSurface: Surface, private val clock: () -> Long = System::nanoTime) {
    fun configure(cfg: EncoderConfig)   // 1080p30 CBR 8 Mbps, keyframe 1 s, High c/ fallback
    fun start()
    fun requestKeyframe()
    fun setBitrate(kbps: Int)
    val output: Flow<EncodedFrame>      // ptsUs, annexb: ByteArray, flags: Int
    fun stop()
}
// EncodedFrame.flags: bit0 keyframe · bit1 SPS/PPS incluídos
```

## Passos
1. `EncoderConfig` + fallback de perfil (High → Main → Baseline; logar).
2. `MediaCodec` assíncrono; loop de drain da saída; reassemblagem Annex-B (start codes); `ptsUs` pelo `clock` (registrando a escolha vs `presentationTimeUs` do buffer).
3. Checagem SPS/PPS em keyframes; anexar os guardados quando o encoder não o fizer (armadilha §6).
4. `requestKeyframe()`/`setBitrate()` assíncronos.

   - IT-2.02: bitrate medido em 10 s ≈ 8 Mbps ±15%.
   - IT-2.03: `requestKeyframe()` durante a transmissão → keyframe em ≤300 ms.
