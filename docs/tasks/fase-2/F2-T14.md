## Contexto embutido
- **Quirk do Gradle (F0-T11):** `gradlew connectedDebugAndroidTest` na raiz **falha** no módulo `capacitor-cordova-android-plugins` (classes duplicadas) → sempre `.\gradlew.bat :app:connectedDebugAndroidTest`. Unitários: `.\gradlew.bat :app:testDebugUnitTest` (o CI roda `testDebugUnitTest` na raiz — ok).
- Servidor de teste no PC: `cargo run -p lc-server --example soak_server` (porta 48650, imprime a URI de pareamento, auto-aprova em build debug, stats a cada 10 s). Para o celular pela LAN: confira o bind em `crates/lc-server/src/config.rs` (se amarrar só a 127.0.0.1, rode uma variante local amarrada à LAN e registre).
- APK: `mobile/android/app/build/outputs/apk/debug/app-debug.apk`. Deep link via adb: `adb -s RXCT800A2HR shell am start -a android.intent.action.VIEW -d "localcamera://connect?..." com.localcamera.app`. Screenshot: `adb -s RXCT800A2HR exec-out screencap -p > shot.png`.
- PT-2.05 (partida a frio ≤ 1,5 s): `adb shell am start -W com.localcamera.app` (ler `TotalTime`).
- FT-2.12 (servidor recusa com cada `reason`): por código — `bad_token` (token errado na URI) · `not_approved` (aprovar uma vez e reconectar sem "sempre") · `revoked` (tirar da loja de confiança — a UI do desktop vem na Fase 3; **confirme** como revogar em `crates/lc-server/src/trust` e registre o método) · `busy` (outra sessão ativa) · `timeout` (não decidir antes do timeout do `PENDING`) · `version_mismatch`/`protocol_error` (**confirme** como forçar no servidor; se não houver modo, registre desvio aceito no relatório). Em cada caso: abrir o app com a URI via adb e conferir a tela (screenshot + logcat).
- FT-2.13 (`STREAM_CONFIG`/keyframe perdidos → PC pede keyframe; celular responde ≤ 300 ms): com o stream ativo, enviar `REQUEST_KEYFRAME` do PC (**confirme** um meio — ex.: cliente mínimo via `lc-protocol`/`lc-testkit`; se não houver, registre desvio) e conferir o timestamp no log do servidor.
- AT-2.01 (vetores no Kotlin) roda por gradle (agente); os demais AT/FT ✋ são executados **com o usuário** (passos do §7.3/§7.4) — o agente automatiza o que puder (adb, servidor, screenshots) e registra cada resultado.
